# Feedbackprozess

1. Wer etwas ändert, öffnet einen Pull Request und beschreibt kurz die Änderung.
2. Eine andere Person prüft die Änderung und schreibt ihr Feedback als Kommentar.
3. Die Person, die den Pull Request erstellt hat, setzt das Feedback um.
4. Nach der letzten Prüfung wird der Pull Request gemergt.
